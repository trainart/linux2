
## Field Breakdown

| # | Field Name | Description |
|---|------------|-------------|
| 1 | **Account** | The user's login name. |
| 2 | **Password** | <ul><li>Contains the user's encrypted password</li><li>Shows 'x' if using shadow passwords (actual password stored in `/etc/shadow`)</li><li>`/etc/shadow` is readable only by root</li></ul> |
| 3 | **UID** | The user's numerical identifier:<ul><li>0 = root</li><li>1-999 = system accounts</li><li>1000+ = regular users</li></ul> |
| 4 | **GID** | The numerical identifier of the user's primary group. |
| 5 | **GECOS** | <ul><li>Optional field for user information</li><li>Typically contains the full user name</li><li>May include contact information (called "finger information")</li><li>Example: `John Doe,Office 123,555-1234`</li></ul> |
| 6 | **Home Directory** | The absolute path to the user's home directory. |
| 7 | **Shell** | <ul><li>The absolute path to the user's default shell</li><li>Defaults to `/bin/sh` if empty</li><li>Users can change with `chsh` command</li><li>May be `/sbin/nologin` for system accounts</li></ul> |

## Additional Notes
- Each line represents exactly one user account
- Fields are separated by colons (`:`)
- The file is world-readable but should only be writable by root
- Modern systems typically use shadow passwords (with 'x' in field 2)
